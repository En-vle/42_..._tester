42 Testers

Welcome to 42 Testers!

This repository collection contains a set of testers designed for projects from the 42 School curriculum.

Purpose

The goal of these testers is to help 42 students verify their projects, identify potential bugs, and check whether their implementations behave as expected.

Each tester focuses on a specific 42 project and provides automated tests to make the evaluation process easier.

Repository naming

All repositories follow this naming convention:

42_*_tester

For example:

Milestone 0 :

42_libft_tester
Milestone 1 :
42_printf_tester
42_get_next_line_tester
...
...


How does it work?

The general principle is simple:

Clone the tester corresponding to your project.
Place or configure your project source files as explained in its README.
Run the tester.
Check the results to identify potential issues.
Fix your code and run the tests again.

Each tester may have its own installation instructions and execution commands.

Disclaimer

These testers are provided as development and debugging tools.

Passing all tests does not guarantee a perfect evaluation by the official 42 Moulinette.
They may not cover every possible edge case.
Always make sure you understand your code and follow the subject requirements.
